# Introducción Software
## ¿Qué es un programa informático?
>Un *programa informático* es un **conjunto ordenado de instrucciones**, escritas en un *lenguaje de programación* que un ordenador interpreta y lee para poder **realizar una tarea o resolver un problema**.

## Diferencias entre código fuente, código objeto y código ejecutable:
  ...  | Código Fuente | Código Objeto | Código Ejecutable
---|-------|--------|-----
**Definición** | Instrucciones legibles escritas por *humanos* en un lenguaje de *programación*.| Resultado de traducir el *código fuente a un formato binario*, el ordenador no lo puede entender del todo.| *Archivo final* que resulta de unir y enlazar el código objeto con los recursos y librerías necesarios.
**Quién lo entiende**| Los programadores | El ordenador parcialmente | El sistema operativo y el hardware
**Características**| Se puede leer, modificar y escribir fácilmente, pero *no se puede ejecutar directamente sin antes ser traducido*.|Todavía no se puede ejecutar por sí mismo porque *le faltan piezas o conexiones con otras librerías del sistema*. Suele guardarse en archivos con extensión .obj o .o.| Está *listo para funcionar de inmediato* al hacer clic sobre él.

## Etapas del desarrollo del Software.
![Fases del desarrollo Software](https://viewnext.com//wp-content/uploads/2018/06/7fases_SDLC_infografia.jpg)

 1. **Planificación**: Se *definen los objetivos del proyecto*, los plazos, el presupuesto y los recursos necesarios.
 1. **Requisitos**: Se *recopilan y estudian en detalle las necesidades del cliente* y las funciones que debe cumplir el sistema.
 1. **Diseño**: Se d*efine la arquitectura general del software*, la estructura de la base de datos y las interfaces de usuario.
 1. **Fase de desarrollo y pruebas**: Los programadores escriben el código fuente para *crear las funciones y módulos planeado*s, revisando el programa para *corregir errores* y asegurarse que todo funcione correctamente.
 1. **Puesta en marcha/despliegue**: El software se instala y *se pone en marcha en el entorno real* para que los usuarios puedan utilizarlo.
 1. **Operaciones y mantenimiento**: Es una *fase continua donde se corrigen nuevos fallos*, se mejora el rendimiento y *se añaden actualizaciones*.
 1. **Dsiposición**: Fin del ciclo de vida del sistema y su retiro del funcionamiento.
